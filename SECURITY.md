# Security policy

Please do not disclose a vulnerability in a public issue, discussion, pull request, screenshot or video.

Report it privately to [meowstache.app@gmail.com](mailto:meowstache.app@gmail.com) with the repository name, affected version, impact and the smallest safe reproduction you can provide. Never send real passwords, access tokens, signing keys or unrelated personal data.

You should receive an acknowledgement within seven days. A fix and disclosure timeline depends on severity and the affected upstream services or devices.
